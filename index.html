1. 企业培训方案生成平台 (MVP)

  • 合作方：北京硕领智能科技有限公司
  • 技术栈：Spring Boot, SpringAI, Vue 3, MinIO, PDFBox/POI, Docker Compose
  • 项目描述：针对B端企业培训业务中讲师/课程匹配效率低、手工拼装方案耗时长的问题，开发了一套端到端的智能解决方案生成系统。通过集成 DeepSeek，实现了客户需求自然语言解析、多模态文档结构化信息抽取及个性化方案的自动化生成，将运营人员的方案生成时间由数小时压缩至几分钟。
  • 核心贡献：
    • 设计非结构化文档（讲师简历/课程大纲）自动解析入库链路 (文本清洗去噪 -> 长度硬截断截流 -> LLM 结构化抽取)，规避长文档Token超限，实现结构化字段自动抽取。
    • 设计和调优多个业务Prompt（需求理解、推荐理由生成、摘要总结、段落过渡语生成等），提升生成方案的连贯性和可读性，替代传统模板拼接方式。
    • 设计意图识别与槽位抽取模块，基于 Function Calling 将自然语言转为结构化查询条件，并针对标签字段基数差异做归一化处理。
    • 建立四层评测体系（槽位抽取/归一化/检索/生成）及标注评测集，量化跟踪抽取准确率、幻觉率等核心指标，支撑迭代优化与回归验证。
